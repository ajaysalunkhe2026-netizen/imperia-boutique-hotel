# Imperia Boutique Hotel

Official website project for Imperia Boutique Hotel, Rabale, Navi Mumbai.

## Stack
- Next.js 16.4.6
- React 19.2.1
- TypeScript
- Custom responsive CSS
- Lucide icons

## Development
```bash
npm install
npm run dev
```

Production checks:
```bash
npm run lint
npm run typecheck
npm run build
npm audit
```

## Content and photography integrity
The property address and room-category references on the initial website draft were cross-checked against a third-party travel listing. Hotel management must confirm all room details, amenities, operating information, booking details, and policies before public launch.

The visual design currently uses clearly identified photography placeholders. Third-party listing photographs are not copied into this repository. Replace these with hotel-owned photographs or images for which written usage permission has been obtained.

## Deployment
Connect this repository to Vercel after the build, content review, and photography permissions are complete. Configure the custom domain only after production approval.
